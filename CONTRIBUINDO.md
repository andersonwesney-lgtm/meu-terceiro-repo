# Como contribuir

Obrigado pelo interesse em contribuir com o **meu-terceiro-repo**!

1. **Abra uma issue** descrevendo o problema ou a melhoria antes de começar.
2. **Crie uma branch** a partir da `main` com um nome descritivo, como `feat/nova-funcionalidade` ou `fix/corrige-erro`.
3. **Faça commits pequenos** com mensagens claras, explicando o que mudou.
4. **Abra um Pull Request** para a `main` descrevendo as alterações e referenciando a issue.
5. **Aguarde a revisão**: nenhum PR é mesclado sem ser revisado.
